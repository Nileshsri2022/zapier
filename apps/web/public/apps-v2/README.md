# App icons (served locally from /apps-v2/*)

Brand marks (Gmail, Google Sheets, Google Calendar, GitHub, WhatsApp, Telegram)
are from Simple Icons (CC0), tinted with each brand's colour, downloaded and
vendored here so the UI never hotlinks a third-party CDN. Solana is a local
recreation of its three-bar mark. Email, Webhook and Schedule are generic glyphs
(Lucide-style, ISC). Do not replace these with remote URLs — Flaticon/Icons8
hotlinks break (the previous Solana/Schedule URLs return 404 upstream).
