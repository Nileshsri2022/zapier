What AI Transform is

A data-transformation step inside an automation pipeline (packages/ai/src/prompts.ts:5). It takes text assembled from earlier in the run, asks one provider for a constrained answer, validates that answer locally, and hands two usable forms downstream:

  • output — a string (plain text or JSON.stringify(fields)) for {previousOutput.output}.
  • fields — a typed object for {previousOutput.fields.category} / {stepOutputs.2.fields.orderId} and for stepConditions.

It has no tools, no side effects, no memory, no file input. The spec (§2 Non-goals) is explicit about that. If you need the model to call an API, do it in the next Zap step with the AI's fields as inputs.

What AI Transform is not

Tempting mental modelWhy it misleads
A chatbot inside ZapMateNo conversation memory; each call is one stateless request with a frozen system prompt + framed input. “Memory” is you chaining stepOutputs.
A free/unlimited LLMEvery call is billable against whoever pays the provider (platform account, Puter token, or your BYOK key) and counted toward the Redis daily cap. Test-panel calls bill too.
A place to store secretsAction metadata never holds keys. Platform keys are env vars; BYOK keys are encrypted server-side and resolved at execution via @repo/ai-connections. They never appear in outputs or errors.
Guaranteed correctValidation checks shape (required fields, types, enums, bare numbers), not truth. The prompt says “Do not invent facts” — that reduces hallucination, it does not eliminate it.

The contract in one glance

{
  "provider": "openai_compatible",
  "connectionId": "<owned AiConnection id>", // only for that provider
  "model": "<model id>",                    // required for compatible; else optional
  "mode": "extract",                         // summarize | classify | extract | custom
  "instructions": "Extract order details",    // never templated; ≤4000 ch (required for custom)
  "input": "{raw}",                           // template; ≤4000 ch — the only templated field
  "outputFields": [                           // 1–25 for extract; optional for custom
    { "name": "orderId", "type": "text", "isRequired": true }
  ],
  "temperature": 0,                          // 0–1, default 0
  "maxOutputTokens": 500                     // 16–2000, capped by AI_MAX_OUTPUT_TOKENS
}

From reports/ai-reasoning-step-spec.md §4.2, enforced by AiActionMetaDataSchema (packages/types/src/ai.ts) and validateAiConfig (packages/ai/src/config.ts). Unknown keys are stripped; classify and extract have mode-specific required fields.
